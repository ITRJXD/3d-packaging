# 3D 包材设计工具

输入纸箱尺寸，生成二维刀版并查看三维折叠效果；通过子母箱页面计算装箱方案。

开发者：Perry · 公众号：软件小邓

## 快速使用

下载或克隆本仓库，直接用现代浏览器打开 `index.html`，无需安装、构建或启动服务。请保持 `index.html` 和 `packing.html` 在同一目录。

```bash
git clone https://github.com/perry46638/3d-packaging.git
```

本仓库为私有仓库，克隆与推送需要拥有访问权限。

## 包材设计

- 输入长、宽、高，实时联动二维刀版与三维预览，支持 mm、cm、m 单位切换。
- 刀版左上方显示长宽高标题（L × W × H）；页面、SVG／PDF 模板及刀版展示导出统一携带当前尺寸与单位。展示导出关闭刀版尺寸时同时隐藏标题。
- 拖拽旋转、滚轮缩放、Shift 拖拽平移；可查看缩放比例，一键居中保留当前角度与比例。
- 点击刀版定位对应面；普通模式选择面，展开模式点击面控制折叠与展开。
- 支持整体折叠进度、展开／半折／合上、动画播放及 XYZ 方向提示。
- 为六个面分别上传图片，调整缩放、位移和旋转，或导入整张成稿。
- 支持 SVG、PDF、兼容 PDF 的 AI 文件及图片；普通 AI 文件不保证能直接解析，可先转为 SVG 或 PDF。
- 导出模板或可编辑成稿 SVG；展示图支持刀版、3D 或全部，下载前在页面内预览。
- 可分别设置刀版与 3D 尺寸标注，保存多个当前视图、调整顺序并批量导出。
- 点击已保存视图放大查看，通过左右箭头或键盘 ←／→ 循环切图，顺序与列表一致，不受导出勾选影响。支持滚轮缩放、拖拽移动、双击放大／还原及适应窗口；切图恢复适应窗口。
- 移除成稿时同步清除已保存视图。

### 建议设计流程

1. 选择单位，输入纸箱尺寸。
2. 导出模板，在设计软件中完成排版。
3. 导入成稿，检查各面图案位置与折叠方向。
4. 调整折叠状态和视角，保存需要展示的多个视图。
5. 选择导出内容、格式及尺寸标注，预览后下载。

### 矢量与图片说明

SVG 成稿导出尽量保留原始矢量对象；上传的 JPG、PNG 等位图不会自动转成矢量。当前 PDF 展示导出将各面图案保留为可单独移动的图片对象，刀线和尺寸为矢量，并不保证原稿中的文字和图形均可逐个编辑。需要继续编辑原始矢量对象时，优先使用可编辑成稿 SVG。

浏览器本地缓存用于恢复最近成稿及已保存视图；清理浏览器数据、更换浏览器或打开不同路径可能影响恢复。重要成稿请自行保留源文件，Git 不会备份浏览器缓存。

## 子母箱装箱

打开 `packing.html`，或从主页面点击“子母箱装箱”。

- 输入子箱外尺寸、数量和单个毛重，实时计算推荐摆放与母箱尺寸。
- 支持指定每箱装几个，或按总数量推荐装箱方案。
- 可设置允许侧放、箱内留量、母箱板厚、空箱重量，以及最长边、三边和、整箱毛重限制。
- 支持透视、俯视、正视、侧视，并提供尺寸和方向参照，支持 mm、cm、m。

计算结果用于方案预估。实际尺寸和重量取决于板材、缓冲材料及生产公差，应以打样结果为准。

## 查看迭代与恢复旧版

仓库首页点击 **Commits** 查看每次修改。进入某条提交可比较变更，点击 **Browse files** 查看该版本完整代码。历史代码统一由 Git 管理，不再另外复制历史版本文件夹。

最初导入的历史文件仍可在初始提交 `27e4799` 中查看。

本地查看记录与修改：

```bash
git log --oneline
git show <提交编号>
```

更新前先确认工作区状态；没有未提交改动时可同步远程更新：

```bash
git status
git pull --ff-only
```

完成修改并验证后提交、上传：

```bash
git add index.html packing.html README.md .gitignore
git commit -m "简要说明本次修改"
git push
```

只提交到本地的版本需要推送后才会在 GitHub 上可见。GitHub 令牌、用户成稿及浏览器缓存均不要写入代码仓库。
