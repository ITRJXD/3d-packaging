# 3D 包材设计工具

输入纸箱尺寸，生成二维刀版，查看三维折叠效果，并导入包装成稿检查各面图案。附带独立的子母箱装箱计算页面。

- 当前版本：**1.1.1**
- 仓库：[ITRJXD/3d-packaging](https://github.com/ITRJXD/3d-packaging)
- 开发者：Perry · 公众号「软件小邓」
- 更新记录：[CHANGELOG.md](CHANGELOG.md)

## 开始使用

下载仓库 ZIP 并完整解压，使用支持 WebGL 的现代浏览器打开 `index.html`。需要装箱计算时，点击页面上的入口，或打开同目录的 `packing.html`。

也可以使用 Git 下载：

```bash
git clone https://github.com/ITRJXD/3d-packaging.git
cd 3d-packaging
```

无需安装依赖、构建或启动后端。两页均保留 HTML 内嵌资源的方式，可直接双击打开；移动项目时建议保留整个文件夹。浏览器必须允许脚本运行；3D 预览和同画面导出需要 WebGL 可用。

## 包材设计

| 功能 | 说明 |
| --- | --- |
| 尺寸与单位 | 输入长、宽、高，支持 mm、cm、m，联动刀版与 3D 预览 |
| 折叠 | 整体进度、展开／半折／合上、动画，以及展开模式下单个面的开合 |
| 视角操作 | 拖动旋转、滚轮缩放、Shift 拖动平移、居中、重置及坐标轴提示 |
| 面板选择 | 点击刀版或 3D 面板选择；点击刀版可定位对应面 |
| 素材 | 导入整张成稿，或为六个面单独上传图片并调整位置、比例与角度 |
| 尺寸标注 | 刀版与 3D 分别控制；刀版标题显示当前长宽高与单位 |
| 保存视图 | 保存当前画面，勾选导出、调整顺序、放大查看和切图 |

### 推荐流程

1. 选择单位，输入纸箱尺寸。
2. 导出刀版模板，在设计软件中完成排版。保留完整画板、比例与留白。
3. 导入成稿，确认尺寸和各面图案；部分本工具导出文件可通过尺寸标记识别尺寸。
4. 调整折叠状态、视角及标注，保存需要的视图。
5. 打开展示导出，选择刀版、3D 或全部，检查预览与编辑范围提示后下载。

### 导入格式

| 格式 | 处理方式与要求 |
| --- | --- |
| SVG | 浏览器生成预览，导出时尽量保留路径和文字 |
| PDF | 生成兼容图片预览，放大时按需提高分辨率；导出另行尝试提取矢量 |
| AI | 需要保存为包含 PDF 兼容内容的 AI；不支持所有原生 AI 文件 |
| PNG／JPG／WebP 等图片 | 作为位图使用，不自动转换为矢量 |

整张成稿必须与当前模板比例相符。PDF 会查找比例匹配的页面；受密码保护、损坏或不受支持的文件可能无法读取。当前导入文件大小上限为 80 MB。

## 导出与编辑范围

模板导出与展示导出用途不同：模板用于平面设计，展示导出用于查看刀版及折叠后的效果。

| 导出入口 | 可选内容 |
| --- | --- |
| 模板 | SVG 刀版模板、可编辑成稿 SVG、PDF、AI（PDF 兼容内容） |
| 展示：刀版 | SVG 或 PDF，包含当前素材，可选择尺寸标注 |
| 展示：3D | PDF、PNG 或多视图 PNG ZIP |
| 展示：全部 | 多页 PDF，或刀版 SVG 与 3D PNG ZIP |

AI 选项输出的是 PDF 兼容内容，不代表原生 Illustrator 工程文件。PNG 展示图为透明背景，PDF 展示页为白底。

### 什么可以编辑

| 对象 | 实际编辑范围 |
| --- | --- |
| 刀线、折线、尺寸 | 矢量对象，可在兼容设计软件中编辑 |
| SVG 与成功提取的 PDF／AI 矢量素材 | 尽量保留路径与文字；不保证还原源文件图层和对象结构 |
| 已转曲文字 | 可编辑轮廓，不能恢复为可直接输入的文字 |
| 用户位图或矢量提取失败的素材 | 作为图片移动、缩放；内部文字和图形不能逐个修改 |
| 3D 矢量视图 | 面板与透视裁切对象，用于展示，不能还原为平面排版 |
| 旧版图片视图 | 保留为图片，不能自动补回矢量对象 |

PDF／AI 的兼容预览与矢量提取互相独立。复杂渐变、透明组或绘图指令可能无法转成可编辑矢量；此时保留图片，并在导出提示中说明原因。字体及设计软件兼容性会影响结果，重要文件应在目标设计软件中检查。

## 已保存视图与本地记录

- 点击视图放大，使用左右按钮或键盘方向键切换；支持缩放、拖动和适应窗口。
- 查看顺序与列表一致，不受导出勾选影响。
- 最近成稿和已保存视图存入当前浏览器的 IndexedDB。
- 移除成稿会同步清空已保存视图；清理浏览器数据、更换浏览器或打开路径可能影响恢复。
- 浏览器记录不等于源文件备份，也不会随 Git 提交上传。请另行保留重要源稿和导出文件。

## 子母箱装箱

打开 `packing.html`：输入子箱尺寸、数量与单个毛重，计算母箱方案及摆放方式。

支持指定每箱数量或按总数量推荐装箱；可设置允许侧放、箱内留量、板厚、空箱重量、最长边、三边和及整箱毛重限制，并查看不同方向和分层摆放。

计算用于方案预估。实际装箱尺寸及重量需结合板材、缓冲材料和生产公差打样确认。

## 文件体积与性能

`index.html` 约 16 MB，主要来自内嵌中文字体、PDF 解析资源和矢量导出引擎，业务脚本约 0.15 MB。资源虽按功能使用，但 HTML 本身仍需完整读取；本版没有通过拆分文件减少首次读取量。

1.1.1 减少了以下重复工作：

- 成稿、模型和贴图清晰度档位未变时，旋转不再反复查询贴图 DOM。
- GPU 顶点上传数组和缓冲区复用，颜色解析结果缓存。
- 放大视图时只生成当前图片，最多缓存三张。
- 连续保存请求合并为最新状态，清空成稿时保留事务顺序。
- 子母箱拖动、滚轮事件通过动画帧合并绘制。

高清图片裁切仍需要像素扫描，3D 矢量透视导出仍包含细分与裁切计算，多视图或复杂成稿可能耗时。当前优化通过语法和模拟逻辑检查，尚无浏览器 FPS、真实文件耗时或 Illustrator 编辑效果的完整测试报告。

## 常见问题

**成稿比例不符**：检查当前长宽高、导出画板和留白，优先基于本工具模板设计。

**AI 无法导入**：在 Illustrator 中启用 PDF 兼容保存，或另存为 SVG／PDF。

**PDF 素材不能逐项编辑**：查看导出提示是否降级为图片；已转曲文字和原始位图本身也有限制。

**3D 无法显示或导出**：检查浏览器 WebGL 和硬件加速是否可用，再尝试更新浏览器。

**刷新后记录丢失**：确认使用相同浏览器及路径，并检查是否使用隐私模式或清理了浏览器数据。

## 文件结构与维护

| 文件 | 用途 |
| --- | --- |
| `index.html` | 刀版、成稿、3D 预览、视图管理及导出，含内嵌资源 |
| `packing.html` | 子母箱装箱计算与预览 |
| `VERSION` | 当前版本号 |
| `CHANGELOG.md` | 修改内容、验证结果与已知限制 |
| `README.md` | 使用说明与维护约定 |

每次修改同步 `VERSION`、两页的 `application-version` 和修改日志。关键模块保留中文注释；第三方内嵌资源保持原样。

历史代码由 Git 管理。使用 `git log --oneline` 查看提交，使用 `git show <提交编号>` 查看变更。修改先本地检查，用户确认后再推送 GitHub；浏览器成稿、缓存和访问令牌不应加入仓库。
